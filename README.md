# Fable5Temp — AI Agent 運作制度庫

這個 repo 不是軟體專案。它存放 Claude Code / AI agent 長期運作的制度：
路由、模型調度守則、派工模板、判斷 rubric、維護協議。

- **AI agent 入口**：`CLAUDE.md`（每個 session 自動載入的路由與紅線）
- **人類讀者入口**：`ai-rules/00-diagnosis.md`（整套制度的為什麼）
  → `ai-rules/90-letter.md`（建立制度時的脈絡與取捨）
- 制度初版建立於 2026-07-04，由一次性的較強模型 session 完成；
  之後由日常模型依 `ai-rules/40-maintenance.md` 的協議維護。
